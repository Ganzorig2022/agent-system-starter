# Agent entry point

This repo uses the `.agent/` convention.

**Start here:** read `.agent/README.md` — it is the single source of truth for
the session-startup protocol. Do not act before completing it.

Also apply any directly relevant harness customization, such as local/global
skills, rules, commands, or specialist prompts. Those layers refine workflow;
`.agent/` still owns repo state, plans, decisions, and handoffs.

`CLAUDE.md` and `AGENTS.md` are intentionally identical; edit both together.
